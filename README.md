# Angsuman Das — academic site

Source for https://angsumi.online/cv/, the research profile of Angsuman Das (PhD researcher, computational microbiome science and machine learning, Mizoram University).

- `index.html` — research profile: statement, featured projects, publications, skills with evidence, teaching, awards, contact.
- `full-cv.html` — complete, printable CV (use the browser's *Save as PDF*).
- `academic.css` — shared styles for both pages (light/dark, print).
- `download.html` — supporting academic documents.

Deployed by `.github/workflows/deploy.yml` on every push to `main`.
