# Interactive CV

A personal interactive resume and CV portfolio built as a web application. It elegantly showcases credentials, projects, and work experience, providing visitors and recruiters with an engaging way to explore professional achievements. It also includes an easy way to download a static copy of the resume.

## 🌟 Features
- **Interactive Portfolio:** Dynamic display of skills, experiences, and projects.
- **Responsive Design:** Looks great on desktop and mobile.
- **Downloadable CV:** Direct link to download credentials and resume in a static format.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript

## 🚀 Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Angsumi/cv.git
   ```
2. **View Locally:**
   Open `index.html` directly in your browser.
